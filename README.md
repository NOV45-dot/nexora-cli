# NEXORA

**Security. Intelligence. Control.**

NEXORA is a Python-based cybersecurity and network intelligence CLI designed for Termux and Linux.

## Features

- 🌐 Network intelligence
- 🔍 DNS lookup
- 🌍 Public IP detection
- 🔐 SHA-256 file hashing
- 🛡️ Password strength checking
- 📡 Authorized host scanning
- 🐧 Linux command assistant
- 📚 Cybersecurity learning center
- 💻 System information
- 🩺 NEXORA system diagnostics

## Installation

```bash
git clone https://github.com/NOV4-dot/nexora-cli.git
cd nexora-cli
