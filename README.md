## 🚀 What is NEXORA?

NEXORA is a Python-based command-line toolkit for cybersecurity learning, network diagnostics, system information, and authorized security testing.

> ⚠️ NEXORA is intended for educational and authorized security testing only.

## ✨ Features

- 🌐 Network Intelligence
- 🔍 DNS Lookup
- 🌍 Public IP Detection
- 🔐 SHA-256 File Hashing
- 🛡️ Password Strength Checking
- 📡 Authorized Host Scanning
- 🐧 Linux Assistant
- 📚 Cybersecurity Learning Center
- 💻 System Information
- 🩺 System Diagnostics
